設定

垃圾庫位置

每天一個資料夾，裡面是 index.md（可直接讀的 Markdown）、page.json 和 files。換位置不會搬舊資料，要搬請自己把整個資料夾移過去。

全域快捷鍵

點一下輸入框，再按你要的組合鍵。在任何程式裡按它，就會叫出或收起這個視窗。

開機啟動要用打包好的版本才會生效。

打字時的快速格式與快捷鍵

/叫出格式選單，繼續打字可以篩選，Enter 套用
# 空格大標題（## 中標、### 小標）
- 空格項目符號
1. 空格編號清單
[ ] 空格待辦勾選
> 空格引言
--- 分隔線
Ctrl+B / Ctrl+I粗體 / 斜體
Tab / Shift+Tab清單縮排 / 退回
Alt+↑ / Alt+↓把這一塊（或清單裡這一項）往上 / 往下搬
左邊的抓手滑鼠移到某一塊才出現：拖曳搬動，點一下選取整塊；旁邊那顆是複製整塊
Ctrl+V貼上文字、網址、截圖、檔案（格式會保留）
Ctrl+Shift+V貼成純文字
Ctrl+O選檔案
Alt+T插入現在時間
Alt+← / Alt+→前一天 / 後一天
Ctrl+T回到今天
Ctrl+G月曆
Ctrl+F搜尋
Ctrl+Z復原
Esc關掉面板；沒有面板時收起視窗
