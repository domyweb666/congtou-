垃圾庫位置

每天一個資料夾，裡面是 index.md（可直接讀的 Markdown）、page.json 和 files。換位置不會搬舊資料，要搬請自己把整個資料夾移過去。

全域快捷鍵

點一下輸入框，再按你要的組合鍵。在任何程式裡按它，就會叫出或收起這個視窗。

快捷鍵與快速格式

丟進來、撈回去

Ctrl V貼上文字、網址、截圖、檔案（格式會保留）
Ctrl Shift V貼成純文字
Ctrl O選檔案放進這一頁
Ctrl Shift C複製游標所在的整塊（含格式）；滑鼠移到那一塊，左邊也有同一顆按鈕
Enter選到檔案或圖片時打開它（滑鼠點兩下也行）
Ctrl F搜尋所有日子（結果列在左邊側邊欄）
Ctrl Z復原

換日子

Alt ← Alt →前一天、後一天
Ctrl T回到今天
Ctrl G月曆；打開後用方向鍵選日子、PageUp 和 PageDown 換月

打字時的快速格式

/叫出選單：第一項是放圖片或檔案，其餘是格式。繼續打字可以篩選，Enter 套用
# 空格大標題（## 中標、### 小標）
- 空格項目符號
1. 空格編號清單
[ ] 空格待辦勾選
> 空格引言
---分隔線
框起一段字上方跳出格式列：轉成標題或清單、粗體、斜體、刪除線、程式碼、連結、清除格式
Ctrl B Ctrl I粗體、斜體
Ctrl K把選起來的字加上連結
Tab Shift Tab清單縮排、退回
Alt ↑ Alt ↓把這一塊（或清單裡這一項）往上、往下搬
Alt T插入現在時間
